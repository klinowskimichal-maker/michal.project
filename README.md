# Klasyczne Łodzie — projekt Michała

Główne repozytorium projektu aplikacji i serwisu poświęconego klasycznym oraz zabytkowym łodziom i tradycyjnemu szkutnictwu.

## Zakres projektu

- katalog marek i modeli klasycznych łodzi według krajów,
- historia marek i poszczególnych modeli,
- lata produkcji modeli,
- wyszukiwarka ofert z poprawnym filtrowaniem materiału kadłuba (np. drewno / laminat),
- podlinkowany spis modeli po wyborze kraju,
- Księga Założycielska i materiały PDF,
- sekcja Stowarzyszenia,
- galeria i materiały fotograficzne,
- wersja polska i angielska,
- docelowa identyfikacja: granat, miedź/mosiądz i biel.

## Kierunek rozwoju

Projekt będzie rozwijany etapami. Zmiany w kodzie powinny być wersjonowane w GitHub, tak aby można było kontrolować historię i bezpiecznie wracać do wcześniejszych wersji.

## Dokumentacja źródłowa

Materiały projektu obejmują m.in. Księgę Założycielską oraz dokumentację koncepcyjną Polskiego Stowarzyszenia Klasycznych i Zabytkowych Łodzi oraz Tradycyjnego Szkutnictwa.
